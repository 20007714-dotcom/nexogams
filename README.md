# 🎮 NEXOGAMS - Tienda y Catálogo de Videojuegos

Aplicación web interactiva desarrollada de forma individual como proyecto final bajo metodologías ágiles (Scrum/Jira) y control de versiones en GitHub. Permite explorar un catálogo de videojuegos, visualizar disponibilidad de stock en tiempo real, calcular descuentos dinámicos y gestionar un carrito de compras.

## 🚀 Enlace al Proyecto en Vivo
👉 **[Visitar NEXOGAMS aquí](https://20007714-dotcom.github.io/nexogams/)**

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **CSS3:** Diseño oscuro (*Dark Mode*), tarjetas responsivas con CSS Grid y Flexbox.
* **JavaScript (ES6+):** Manipulación dinámica del DOM, cálculo de descuentos (`calcularDescuento`), validación de inventario (`evaluarStock`) e interactividad del carrito (`agregarAlCarrito`).
